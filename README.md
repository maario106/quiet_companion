## 🇪🇸 Español

### 📖 Sobre el Proyecto
**Quiet Companion** es una aplicación móvil diseñada para combatir la soledad no deseada en personas mayores mediante el uso de Inteligencia Artificial conversacional. Este proyecto se desarrolla como Trabajo de Fin de Grado (TFG) y busca crear un puente tecnológico accesible, empático y proactivo para mejorar el bienestar emocional de la *Silver Economy*.

A diferencia de los asistentes virtuales tradicionales (orientados a la productividad), esta aplicación prioriza la **compañía, la empatía y la accesibilidad cognitiva**, adaptándose a las necesidades de los usuarios de edad avanzada.

### ✨ Características Principales (MVP)
* **🗣️ Interfaz Prioritaria por Voz:** Minimiza la necesidad de teclear, superando la brecha digital y facilitando la comunicación natural.
* **🎨 Diseño Accesible:** Interfaz de usuario (UI) simplificada, con alto contraste, tipografía legible y botones de gran tamaño.
* **🧠 IA Empática (LLM):** Integración con modelos de lenguaje avanzados mediante *Prompt Engineering* específico para mantener un tono paciente, cercano y seguro.
* **📅 Memoria Contextual (Próximamente):** Capacidad de recordar preferencias y estados de ánimo previos del usuario para conversaciones más personalizadas.

### 🛠️ Stack Tecnológico Propuesto
* **Frontend / App Móvil:** Flutter
* **Backend & Base de Datos:** Firebase - Flutter
* **Inteligencia Artificial:** [API de OpenAI (GPT-4o mini) / Claude 3 / Gemini --> Por determinar]
* **Gestión de Proyecto:** Metodología Híbrida (Personal Kanban + Lean Startup).

## 🇬🇧 English

### 📖 About the Project
**Quiet Companion** is a mobile application designed to combat unwanted loneliness in the elderly through conversational Artificial Intelligence. This project is developed as a Final Degree Project (TFG) and aims to create an accessible, empathetic, and proactive technological bridge to improve the emotional well-being of the *Silver Economy*.

Unlike traditional virtual assistants (which are productivity-oriented), this application prioritizes **companionship, empathy, and cognitive accessibility**, adapting to the needs of older users.

### ✨ Key Features (MVP)
* **🗣️ Voice-First Interface:** Minimizes the need for typing, overcoming the digital divide and facilitating natural communication.
* **🎨 Accessible Design:** Simplified User Interface (UI) with high contrast, readable typography, and large buttons.
* **🧠 Empathetic AI (LLM):** Integration with advanced language models using specific *Prompt Engineering* to maintain a patient, warm, and safe tone.
* **📅 Contextual Memory (Coming Soon):** Ability to remember the user's previous preferences and moods for highly personalized conversations.

### 🛠️ Proposed Tech Stack
* **Frontend / Mobile App:** Flutter
* **Backend & Database:** Firebase
* **Artificial Intelligence:** OpenAI API (GPT-4o mini) / Claude 3 / Gemini --> To be determined
* **Project Management:** Hybrid Methodology (Personal Kanban + Lean Startup).
